# Upstream attribution

The Paply Gateway admin frontend is derived from the Octopus frontend:

- Source: https://github.com/bestruirui/octopus
- Upstream commit: `a9f65c8d45e98bd65e95db7d80ec2c38409bc96e`
- Upstream license: GNU Affero General Public License v3.0
- Imported on: 2026-08-20

Paply modifications replace the upstream product branding, authentication and
API integration, reduce navigation to Gateway operations, and add Paply's
model-node, user-budget, health and LiteLLM control-plane workflows. The
frontend source in this directory remains available under the AGPL-3.0-only
license in `LICENSE`.
